# Problem Statement & Project Scope

## 1. Project Title
**Algorithmic Mathematical & Number Theory Toolkit (CLI)**

## 2. Course Alignment
* **Course:** CSE1021 - Introduction to Problem Solving and Programming
* **Domain:** Computational Problem Solving, Top-Down Algorithm Design, Modular Python Development, Array Processing, and Number Theory.

## 3. Problem Statement
In introductory computer science and engineering coursework, students and developers frequently require lightweight tools to compute, analyze, and test fundamental numerical algorithms—such as Euclidean GCD, prime factorization, modular exponentiation, base conversions, and array manipulations. Existing commercial tools are often heavyweight or lack modular algorithmic transparency. There is a need for a unified, clean, modular Command-Line Interface (CLI) application built strictly in Python that executes these fundamental syllabus algorithms with robust input validation and activity logging.

## 4. Objectives & Scope
* **Modular Architecture:** Organize core mathematical logic across 7 distinct backend Python modules within a structured package.
* **Functional Coverage:** Implement Euclidean factoring, prime sieves, Fibonacci analytics, binary modular exponentiation, array order reversal, array partitioning, duplicate filtering, and base/ASCII conversions.
* **Non-Functional Rigor:** Incorporate input validation to prevent runtime crashes and implement timestamped execution logging in `execution.log`.
* **Execution Environment:** Run entirely in terminal/command-line environments using standard Python 3 standard libraries without third-party dependencies.

## 5. Target Audience
* First-year engineering students exploring fundamental Python algorithms.
* Academic evaluators reviewing CSE1021 computational problem-solving projects.
